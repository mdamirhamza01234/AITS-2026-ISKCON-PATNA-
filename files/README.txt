Apni saari PDF aur HTML files isi folder (files/) mein daalo.
Delete mat karna is README ko, bas baaki files iske saath rakh do.

Naam ke rules (build script khud pehchanti hai):
- .html file            -> Mock Test
- .pdf jisme "key", "ans" ya "solution" likha ho -> Answer Key / Solution
- baaki .pdf            -> Question Paper
- Set number: file ke naam mein test/part/set/aits ke baad ka 1-2 digit number

Ek set ke liye teen alag-alag files honi chahiye (paper, solution, mock).
